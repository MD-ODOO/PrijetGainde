# Audit Gainde

Module d'audit et conformité pour le système Gainde2000

## Description

Ce module Odoo fournit une solution complète de gestion d'audit et de conformité pour le système Gainde2000. Il permet de :

- Planifier et gérer les audits
- Documenter les domaines d'audit
- Enregistrer les missions d'audit
- Identifier et gérer les risques
- Documenter les constatations d'audit
- Suivre les actions correctives recommandées
- Générer des rapports d'audit

## Installation

1. Clonez ce dépôt dans votre dossier `custom_addons` d'Odoo
2. Redémarrez votre serveur Odoo
3. Activez le mode développeur
4. Allez dans Applications et recherchez "Audit Gainde"
5. Cliquez sur "Installer"

## Dépendances

Ce module dépend des modules Odoo suivants :
- `base`
- `mail`
- `hr`
- `web`
- `spreadsheet_dashboard`

## Fonctionnalités

### Plans d'Audit
Créez et gérez des plans d'audit structurés

### Domaines d'Audit
Définissez les domaines à auditer

### Missions d'Audit
Enregistrez les détails des missions d'audit

### Gestion des Risques
Identifiez et classez les risques

### Constatations
Documentez les constatations de l'audit

### Actions Correctives
Suivez les recommandations et actions correctives

### Contrôles
Documentez les contrôles mises en place

### Rapports
Générez des rapports détaillés d'audit
